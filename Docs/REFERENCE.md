# Справочник полей

Этот файл создаётся скриптом `Tools/build_data.py` из схемы данных — руками его не правят.
Описания и допустимые диапазоны лежат в `Game/schema/fields.yaml`.

Общие правила записи:

- время — в секундах, расстояния — в сантиметрах, углы — в градусах;
- `id` — короткое имя латиницей без пробелов (`husk_slash`); по нему сущности ссылаются друг на друга;
- текст, который начинается с `#` или похож на число либо на `yes` / `no`, берётся в кавычки: `"#B0503A"`;
- поле можно не писать — тогда действует значение по умолчанию.

## Действие

Где пишется: `Game/data/*.yaml`, секция `Actions`.

Одно действие персонажа: атака, уклонение, блок, реакция на удар, смерть. Это таймлайн в секундах: что и когда происходит, задают окна `Windows`.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Id` | id | обязательно |  | Имя действия. На него ссылаются слоты, комбо и профили ИИ. |
| `Duration` | число | обязательно | ≥ 0 | Длительность в секундах. 0 — действие длится, пока удерживается кнопка (блок). |
| `StaminaCost` | число | 0 | ≥ 0 | Сколько выносливости тратится при старте. Начать можно, если выносливость выше нуля. |
| `StaminaRegenScale` | число | 1 | ≥ 0 | Множитель восстановления выносливости, пока идёт действие (в блоке — меньше 1). |
| `Windows` | список: см. «Окно действия» | — |  | Окна: когда бьёт оружие, когда персонаж неуязвим, блокирует, может прервать действие. |
| `ComboNext` | id | — |  | Действие, которое начнётся вместо обычного, если ту же кнопку нажать во время этого. Так строится комбо. |
| `AutoNext` | id | — |  | Действие, которое начнётся само, когда это закончится. Так строятся серии ударов врагов. |
| `DamageScale` | число | 1 | ≥ 0 | Множитель урона оружия для этого удара. |
| `PoiseDamageScale` | число | 1 | ≥ 0 | Множитель урона по балансу для этого удара. |
| `Unblockable` | true / false | false |  | Удар проходит сквозь блок и идеальный блок. |
| `MoveDistance` | число | 0 | ≥ 0 | Рывок: на сколько сантиметров персонаж сдвинется между MoveStart и MoveEnd. |
| `MoveStart` | число | 0 | ≥ 0 | Когда начинается рывок. |
| `MoveEnd` | число | 0 | ≥ 0 | Когда рывок заканчивается. |
| `MoveDirection` | `Forward` / `Backward` / `Input` | Forward |  | Куда рывок: вперёд, назад или куда хочет персонаж (стик у игрока, к цели у врага; без ввода — назад). |
| `SnapFacing` | true / false | false |  | В первый кадр повернуться к цели (или в сторону движения). |
| `TrackingEnd` | число | 0 | ≥ 0 | До этой секунды персонаж продолжает доворачиваться к цели. Чем больше, тем труднее увернуться. |
| `MoveSpeedScale` | число | 0 | 0 … 1 | Доля обычной скорости ходьбы, доступная во время действия. 0 — персонаж стоит на месте. |
| `Animation` | текст | — |  | Путь к анимации. Необязательно: без неё действие работает так же, просто без движения модели. |
| `FitAnimation` | true / false | true |  | Растянуть или сжать анимацию, чтобы она длилась ровно Duration. |

## Окно действия

Где пишется: внутри `Windows` у действия.

Отрезок времени внутри действия, в течение которого что-то включено.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Type` | `Hit` / `Invulnerable` / `Guard` / `PerfectGuard` / `HyperArmor` / `Cancel` | Hit |  | `Hit` — оружие бьёт; `Invulnerable` — удары проходят мимо; `Guard` — блок; `PerfectGuard` — идеальный блок, атакующий оглушён; `HyperArmor` — урон проходит, но не сбивает; `Cancel` — можно начать другое действие. |
| `Start` | число | 0 | ≥ 0 | Секунда от начала действия, когда окно открывается. |
| `End` | число | 0 | ≥ 0 | Секунда, когда окно закрывается. Не указано — до конца действия. |

## Оружие

Где пишется: `Game/data/*.yaml`, секция `Weapons`.

Урон, размер зоны удара, свойства блока и то, какие действия вызывают кнопки.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Id` | id | обязательно |  | Имя оружия. На него ссылается поле Weapon персонажа. |
| `Damage` | число | 10 | ≥ 0 | Урон по здоровью за удар. |
| `PoiseDamage` | число | 10 | ≥ 0 | Урон по балансу за удар. Когда баланс цели кончается, она оглушена. |
| `Reach` | число | 160 | ≥ 1 | Длина зоны удара перед персонажем, в сантиметрах. |
| `Radius` | число | 60 | ≥ 1 | Толщина зоны удара (радиус), в сантиметрах. |
| `GuardDamageReduction` | число | 0.8 | 0 … 1 | Какая доля урона гасится блоком: 1 — весь, 0 — ничего. |
| `GuardStaminaScale` | число | 0.6 | ≥ 0 | Сколько выносливости отнимает каждая единица заблокированного урона. |
| `Actions` | слот → id | — |  | Слот → действие. Обычно здесь `Light`, `Heavy`, `Guard`. |
| `Mesh` | текст | — |  | Путь к модели оружия. Необязательно. |
| `AttachSocket` | id | hand_r |  | Имя кости или сокета, к которому крепится модель оружия. |

## Персонаж

Где пишется: `Game/data/*.yaml`, секция `Characters`.

Игрок, враг или босс: характеристики, оружие, реакции, внешний вид.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Id` | id | обязательно |  | Имя персонажа. По нему враг ставится на уровень. |
| `DisplayName` | текст | — |  | Имя, которое видит игрок (над полосой здоровья босса). |
| `MaxHealth` | число | 100 | ≥ 1 | Здоровье. |
| `MaxStamina` | число | 100 | ≥ 0 | Выносливость. |
| `StaminaRegen` | число | 35 | ≥ 0 | Восстановление выносливости в секунду. |
| `StaminaRegenDelay` | число | 0.8 | ≥ 0 | Пауза после траты выносливости, прежде чем она начнёт восстанавливаться. |
| `MaxPoise` | число | 0 | ≥ 0 | Баланс. 0 — любой удар оглушает (как у игрока). |
| `PoiseResetDelay` | число | 4 | ≥ 0 | Через сколько секунд без ударов баланс восстанавливается полностью. |
| `WalkSpeed` | число | 400 | ≥ 0 | Скорость ходьбы, см/с. |
| `SprintSpeed` | число | 620 | ≥ 0 | Скорость бега, см/с. |
| `SprintStaminaPerSecond` | число | 12 | ≥ 0 | Расход выносливости на бег в секунду. |
| `Weapon` | id | — |  | Оружие персонажа. |
| `Actions` | слот → id | — |  | Слот → действие. Обычно здесь `Dodge` и реакции: `Stagger`, `GuardBreak`, `Parried`, `Death`. |
| `AIProfile` | id | — |  | Профиль поведения. У игрока не указывается. |
| `CurrencyReward` | целое | 0 | ≥ 0 | Сколько осколков получает игрок за убийство. |
| `Boss` | true / false | false |  | Босс: получает большую полосу здоровья внизу экрана и сообщение о победе. |
| `Scale` | число | 1 | 0.1 … 10 | Размер относительно обычного человека. Увеличивает и зону удара. |
| `PlaceholderColor` | текст | — |  | Цвет временной фигуры-заглушки, в кавычках: `"#B0503A"`. |
| `Mesh` | текст | — |  | Путь к модели персонажа. Без неё показывается цветная заглушка. |
| `MeshYaw` | число | -90 | -180 … 180 | Поворот модели, если она смотрит не туда. У большинства моделей −90. |
| `AnimClass` | текст | — |  | Путь к классу анимации. Необязательно. |
| `IdleAnimation` | текст | — |  | Анимация покоя. |
| `MoveAnimation` | текст | — |  | Анимация ходьбы. |

### Слоты действий

Поле `Actions` у оружия и персонажа связывает слот с действием. У персонажа слот перекрывает такой же слот оружия.

| Слот | Когда срабатывает | Где обычно задаётся |
|---|---|---|
| `Light` | лёгкая атака | оружие |
| `Heavy` | тяжёлая атака | оружие |
| `Guard` | блок (удерживаемое действие) | оружие |
| `Dodge` | уклонение | персонаж |
| `Stagger` | реакция на пробитый баланс | персонаж |
| `GuardBreak` | реакция на пробитый блок | персонаж |
| `Parried` | реакция атакующего на идеальный блок противника | персонаж |
| `Death` | смерть | персонаж |

## Профиль ИИ

Где пишется: `Game/data/*.yaml`, секция `AIProfiles`.

Поведение врага: когда замечает игрока, чем и с какой дистанции атакует, какие у него фазы.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Id` | id | обязательно |  | Имя профиля. На него ссылается поле AIProfile персонажа. |
| `AggroRadius` | число | 1200 | ≥ 0 | С какого расстояния враг замечает игрока, в сантиметрах. |
| `LeashRadius` | число | 3000 | ≥ 0 | Как далеко от своего места враг готов уйти, прежде чем бросит погоню и вернётся. |
| `AttackDelayMin` | число | 0.5 | ≥ 0 | Самая короткая пауза между атаками. |
| `AttackDelayMax` | число | 1.5 | ≥ 0 | Самая длинная пауза между атаками. |
| `TurnRate` | число | 360 | ≥ 0 | Скорость поворота к цели, градусов в секунду. |
| `Moves` | список: см. «Атака в профиле ИИ» | — |  | Набор атак. |
| `Phases` | список: см. «Фаза босса» | — |  | Фазы после первой. Нужны боссам. |

## Атака в профиле ИИ

Где пишется: внутри `Moves` у профиля ИИ.

Одна атака из набора врага и условия, при которых он может её выбрать.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `Action` | id | — |  | Какое действие выполнить. |
| `MinRange` | число | 0 | ≥ 0 | Ближе этого расстояния атака не выбирается. |
| `MaxRange` | число | 250 | ≥ 0 | Дальше этого расстояния атака не выбирается. |
| `Weight` | число | 1 | ≥ 0 | Как часто атака выбирается среди подходящих: вес 3 выпадает втрое чаще веса 1. |
| `Cooldown` | число | 0 | ≥ 0 | Сколько секунд атака недоступна после использования. |
| `MinPhase` | целое | 0 | ≥ 0 | С какой фазы атака доступна. 0 — с начала боя. |
| `MaxPhase` | целое | 99 | ≥ 0 | До какой фазы включительно атака доступна. |

## Фаза босса

Где пишется: внутри `Phases` у профиля ИИ.

Фаза начинается, когда здоровье падает до порога. Фазы идут по убыванию порога.

| Поле | Тип | По умолчанию | Диапазон | Что значит |
|---|---|---|---|---|
| `HealthBelow` | число | 0.5 | 0 … 1 | Доля здоровья, при которой начинается фаза: 0.5 — половина. |
| `EnterAction` | id | — |  | Действие при входе в фазу (рёв, смена стойки). Необязательно. |
